# 🔀 Cruzador de Dados

Ferramenta web para **cruzar dois arquivos** por uma coluna-chave e descobrir
rapidamente o que **casa** e o que **falta** entre eles (estilo PROCV/VLOOKUP, só que visual).

Página única (`index.html`), roda no navegador — sem instalação, funciona offline.

## ✨ O que faz

- Sobe **dois arquivos** (`.xlsx`, `.xls` ou `.csv`)
- Você escolhe a **coluna para cruzamento** (a chave) de cada um
- Mostra dois resultados:
  - **Casam** (registros presentes nos dois)
  - **Faltam** (registros que estão em um e não no outro)
- **Filtro** de busca em cada lista
- **Exportar Excel** de cada resultado

## ▶️ Como usar

- **Local:** dê duplo-clique no `index.html`
- **Online (se o GitHub Pages estiver ativo):** `https://sergiomanoel81-ui.github.io/Cruzador-de-Dados/`

1. Carregue os dois arquivos
2. Selecione a coluna-chave de cada um
3. Veja o que casa / falta e exporte pra Excel
